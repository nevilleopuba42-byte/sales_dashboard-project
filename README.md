# sales dashboard-project
interactive sales analysis dashboard built with Microsoft Excel
This project presents an interactive sales dashboard using Microsoft Excel to analyze sales performance across different month,regions,product,categories and sales channels
This dashboard helps identify revenue trends, compare regional performance and understand which products contribute most to total revenue

TOOLS USED
Microsoft excel
pivot tables and pivot charts
slicer and timeline filters
excel formulas and data analysis
data visualization

DASHBOARD FEATURES
interactive region and product category filters
sales channel filtering
date filtering by year,quarter,month and a day
KPI cards for key sales metrics
charts for comparing sales performance
